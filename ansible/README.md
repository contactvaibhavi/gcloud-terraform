# Ansible — GCP VM Configuration

Provision a GCP VM with Terraform and configure it with Ansible. This directory contains both the Terraform config (with Ansible inventory generation) and the Ansible playbook.

## Overview

The workflow is two steps:

1. **Terraform** (`vpc.tf`) — provisions a GCP VM with a static external IP and generates an Ansible inventory file (`cluster.inventory`) from the template.
2. **Ansible** (`packages.yaml`) — connects to the provisioned VM and installs packages.

## Prerequisites

- [Terraform](https://developer.hashicorp.com/terraform/install) >= 1.0
- [Ansible](https://docs.ansible.com/ansible/latest/installation_guide/) >= 2.9
- A GCP service account key file (`key.json`) placed in this directory
- An SSH key pair accessible on your local machine

## Step 1 — Configure Terraform

Edit [vpc.tf](vpc.tf) and replace all placeholder values:

```hcl
variable "ssh_key" {
  default = "/home/youruser/.ssh/id_rsa.pub"   # path to your public key
}

variable "ssh_private_key" {
  default = "/home/youruser/.ssh/id_rsa"        # path to your private key
}

variable "ssh_user" {
  default = "youruser"                           # SSH username on the VM
}

provider "google" {
  credentials = file("key.json")                # GCP service account key
  project     = "your-gcp-project"              # GCP project name
  region      = "us-east4"
}
```

Place your GCP service account JSON key at `ansible/key.json`.

## Step 2 — Provision with Terraform

Run these commands from inside the `ansible/` directory:

```bash
terraform init
terraform plan
terraform apply
```

After `apply` completes, two outputs are printed and `cluster.inventory` is created automatically:

```
instance_ip  = "10.x.x.x"          # internal IP
instance_fip = "34.x.x.x"          # external (floating) IP
```

Verify the inventory was generated:

```bash
cat cluster.inventory
```

It should look like:

```ini
[server]
34.x.x.x

[all:children]
server

[all:vars]
ansible_ssh_user=youruser
ansible_ssh_private_key_file=/home/youruser/.ssh/id_rsa
```

## Step 3 — Run the Ansible Playbook

From the repository root, run:

```bash
ansible-playbook -i ansible/cluster.inventory ansible/packages.yaml
```

Or from inside the `ansible/` directory:

```bash
ansible-playbook -i cluster.inventory packages.yaml
```

The playbook connects to the VM as root (`become: yes`) and installs:

| Package | Purpose |
|---|---|
| `wget` | File download utility |
| `iperf` | Network bandwidth testing (v2) |
| `iperf3` | Network bandwidth testing (v3) |

## Step 4 — Teardown

To destroy all GCP resources:

```bash
terraform destroy
```

## File Reference

| File | Purpose |
|---|---|
| `vpc.tf` | Terraform — provisions VM, static IP, and inventory file |
| `clusterinventory.tpl` | Template for the generated `cluster.inventory` |
| `packages.yaml` | Ansible playbook — installs packages on the VM |
| `key.json` | GCP service account credentials (not committed) |
| `cluster.inventory` | Generated by Terraform after `apply` (not committed) |
